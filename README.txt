16 Guti Master — Facebook App Review policy pages

Files:
- privacy-policy.html
- data-deletion.html

Before submitting to Meta:
1. Publish both files at publicly accessible HTTPS URLs.
2. Open both URLs in a private/incognito browser window to confirm they load without login.
3. In Meta App Review:
   - Privacy Policy URL: use the full URL ending in /privacy-policy.html
   - User Data Deletion type: Data deletion instructions URL
   - Data deletion URL: use the full URL ending in /data-deletion.html

GitHub Pages quick setup:
1. Create a public GitHub repository, for example: 16-guti-master-legal.
2. Upload both HTML files to the repository root.
3. In repository Settings > Pages, enable deployment from the main branch and root folder.
4. Wait for GitHub Pages to publish, then test the two URLs.

Example URLs (replace YOUR_GITHUB_USERNAME):
https://YOUR_GITHUB_USERNAME.github.io/16-guti-master-legal/privacy-policy.html
https://YOUR_GITHUB_USERNAME.github.io/16-guti-master-legal/data-deletion.html

Important:
These pages were drafted based on the supplied game ZIP. The bundle indicates Facebook Instant Games player name access, Facebook player data read/write for session data, and browser local-storage use for settings/session data. Meta/platform and ad providers may separately process information under their own policies. Review the live app and all SDK/ad integrations before submission; update these pages if the app's actual data practices differ.
